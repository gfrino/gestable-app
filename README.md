# GestABLE mobile

Le app per telefono di GestABLE.

| Cartella | App | Stato |
|---|---|---|
| [`GestaVOIP/`](GestaVOIP/) | **GestaVOIP**: softphone per iPhone e Android collegato al modulo Odoo VOIP AI | 0.1.0, da costruire e provare su un telefono vero |

L'app desktop sorella (Odoo AI Desktop, macOS) sta nel repo `gfrino/gestable-desktop`.

Il repo e' pubblico: chiavi, certificati e file di configurazione di Firebase
(`google-services.json`, `GoogleService-Info.plist`) non vanno mai committati.
